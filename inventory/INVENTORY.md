# New-Old Weapons Pack v4.3.0 — опись

Автор мода — SilentFox3 (Kiri) и соавторы, см. CREDITS.md. Описания предметов — авторские, из заголовков схемы (newoldweaponspack.txt), на английском.

«Своё, МБ» — файлы, которые нужны только этому предмету: столько уйдёт из FastDL, если предмет убрать. «Всего, МБ» — вместе с общими файлами.

## Сводка

* В VPK мода: 5986 файлов, 1152 МБ.
* Нужно предметам в игре: 970 МБ (после bz2 для FastDL ≈ 398 МБ, замер).
* Только секретным и отладке: 46 МБ (bz2 ≈ 15 МБ).
* **Ни один предмет не использует: 812 файлов, 130 МБ** — остатки старых версий и вырезанное оружие (orphan.txt). Убираются сборкой.
* **Подменяют файлы игры: 533 файлов, 89 МБ** (override.txt). Через FastDL у клиента не сработают: скачанное игра ищет последним. В FastDL не идут, на сервере остаются.
* Вне VPK: исходники иконок убийств (kill-icons/[nowp_icon_creation_files], 43 МБ) — для художника, игре не нужны; папка mod-n-userscripts — по словам автора «только для личного использования, не для серверов». Обе в сборку не идут.
