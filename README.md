# New-Old Weapons Pack — FastDL для сервера TF2 Classified

Сборка мода [New-Old Weapons Pack v4.3.0](https://gamebanana.com/mods/40389)
(SilentFox3 и соавторы — `CREDITS.md`) для своего сервера:
без неиспользуемых файлов, сжатая bz2, с раздачей клиентам через GitHub
Pages.

Лицензия автора разрешает хостинг для серверов с указанием авторства. На
другие сайты мод не выкладывать: ветка `gh-pages` существует только как
FastDL этого сервера, а `CREDITS.md` лежит в ней рядом с файлами.

## Что получается (замер 16.10.2026, мод v4.3.0)

| | файлов | МБ |
|---|---|---|
| VPK мода | 5986 | 1152 |
| не нужно ни одному предмету (выкинуто) | 812 | 130 |
| на сервер | 5174 | 1022 |
| клиентам (FastDL), до сжатия | 4746 | 944 |
| **клиентам, bz2** | 4746 | **413** |

Сверх того в сборку не идут исходники иконок убийств (43 МБ, для
художника), личные скрипты автора (`mod-n-userscripts`: по его словам,
«не для серверов») и варианты декалей.

Подмены файлов самой игры (533 файла, 89 МБ) идут на сервер, но не в
FastDL: у клиента скачанное игра ищет последним (`gameinfo.txt`), и
подмена не сработает — качать её незачем.

## Шаги

1. **Опись** — `inventory/INVENTORY.md`: 321 предмет по классам, описание
   автора, «своё» место (уйдёт из FastDL, если предмет убрать).
2. **Что вырезать** — `exclude.txt` (по ID, по разделу, по статусу).
3. **Сборка** (Python 3.10+, без сторонних пакетов):
   ```
   python tools/build.py newoldweaponspack_v430.zip ../nowp-out exclude.txt
   ```
   `tools/game_vpks.txt` — пути к VPK игры на машине сборки: по ним
   сборка узнаёт подмены файлов игры и материалы моделей самой игры.
4. **На GitHub**:
   ```
   bash tools/push_fastdl.sh git@github.com:ЛОГИН/РЕПО.git ../nowp-out
   ```
   Репозиторий публичный (иначе клиенты игры не скачают), Pages — с
   ветки `gh-pages`. Скрипт печатает адрес для `sv_downloadurl`.
5. **На сервер** — содержимое `../nowp-out/server/tf2classified/` в папку
   игры, плюс из этого репозитория:
   * `server/addons/sourcemod/plugins/nowp_downloads.smx` — кладёт файлы
     мода в таблицу загрузок (иначе клиенту качается только карта);
   * `server/cfg/nowp_fastdl.cfg` — вписать адрес из шага 4, в
     `server.cfg` добавить `exec nowp_fastdl.cfg`.

   Смена карты. В консоли сервера:
   `[NOWP] в таблицу загрузок: 4746 файлов, нет на сервере: 0; всего в таблице 4747 из 8192`.

## Шапки игрокам (TF2 Classified 3.2.0+)

21 шапка мода (по две на класс и берет на всех) скрыта автором из меню
снаряжения («Super-Secret»; автор просит не раскрывать, как их надеть, —
решение за владельцем сервера). Плагин `nowp_hats.smx`:

* `!hat`, `!hats`, `!шапка` — меню шапок текущего класса и «Без шапки»;
* выбор запоминается за игроком на каждый класс (clientprefs) и
  надевается при каждом появлении и после шкафа снабжения, без дублей;
* `nowp_hat_give <userid> <номер|0>` — то же за игрока (админ, root).

Надевает VScript `scripts/vscripts/nowp_hats.nut` через
`CTFPlayer::GenerateAndWearItem` — у игроков он появился в 3.2.0
(«Chilling Halloween Special», 15.10.2026); раньше был только у ботов.
Список — `configs/nowp_hats.cfg`, его пишет сборка.

## Проверено (локальный сервер Classified, Windows, 16.10.2026, версия 5201 = 3.2.x)

* Схема с вырезанным предметом загружается; боты сами берут оружие мода
  (Aderlasser 3362, Crowbar 3300, AA12 3411, Sub Sandvich 3573 и др.).
* Плагин: 4746 файлов в таблице, предел таблицы — 8192.
* FastDL-путь: файл по адресу `<url>/<путь>.bz2` отдаётся и распаковывается
  в точности в оригинал (локальный HTTP вместо Pages).
* Шапки (21 шт.) надеваются ботам через `GenerateAndWearItem`. Плагин
  `nowp_hats` на боте: выбор надевает, две пересборки снаряжения —
  шапка одна, «без шапки» — снята, чужой класс — отказ. Меню `!hat` и
  запоминание выбора — только живым игроком, не проверено.
* На Хэллоуин у ботов есть маска праздника — шапка надевается поверх
  неё (оба предмета на боте). Как это выглядит — видно только клиентом.

**Не проверено**: клиент игры. Скачает ли клиент Classified по HTTPS (Pages
другого не умеет) — в движке есть libcurl и `cacert.pem`, но заходом
клиента это не проверено; видит ли клиент оружие и шапки без установленного
мода (схему предметов FastDL не передаёт — передаёт ли её сервер сам,
источники не говорят). Проверка: зайти клиентом без мода, в консоли
`download_debug 1; developer 1`.

## Ошибки самого мода (не сборки)

* `Particles: Missing 'particles/nowp_teamfx_vlt.pcf'` — в
  `custom_particles.txt` упомянут, в паке его нет.
* `Variable "$commweapon" is multiply defined in material
  ".../c_soda_popper"` — повтор параметра в материале автора.
